# sdk-ops (retired)

> **This project is retired and archived.** Development continues in **Andromeda**:
> github.com/natuleadan/andromeda

`sdk-ops` was Natuleadan's the Go SDK for provisioning, hardening and operating VPS servers. It has been superseded by Andromeda, a new project that carries its work forward. Please follow the Andromeda repository for documentation, releases and support.

## For Go users

- Every earlier version of `github.com/natuleadan/sdk-ops` is retracted, so `go get` and `go list -m -u` will warn you.
- This module is marked deprecated; no further versions will be published.
- There is no drop-in upgrade path. Start from the Andromeda repository.
